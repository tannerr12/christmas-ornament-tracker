# Christmas Ornament Tracker 🎄

Interactive Christmas decoration map, searchable individual photo inventory, and reusable arrangement guide.

**2026 snapshot:** 203 identified decorations across 27 display locations, using 44 reference photos. The kitchen update adds 36 new objects, four photo locations, and re-links existing TVK-03 to its close-up without double-counting.

## Site

When GitHub Pages is enabled under **Settings → Pages → Source: GitHub Actions**, the site is expected at:

https://tannerr12.github.io/christmas-ornament-tracker/

This first deployment uses a self-contained archive of the photo-based tracker, split into 44 text chunks to accommodate the connected GitHub upload limits. `index.html` loads the chunks and restores the full interactive page in the browser. No database is needed.

### Important

- This is a **public repository**, and the embedded photographs include interiors of a private home and potentially family pictures.
- Browser-side edits are local; export CSV/JSON to save them. Changes do not automatically sync back to GitHub.
- Update the website from the original project source rather than hand-editing the numbered chunks.
