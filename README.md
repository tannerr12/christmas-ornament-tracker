# Christmas Ornament Tracker 🎄

An interactive, photo-based inventory of Christmas decorations and where to place them each year.

**2026 snapshot:** 167 decorations, 23 display areas, 40 reference photos.

GitHub Pages deployment is planned at https://tannerr12.github.io/christmas-ornament-tracker/.

This is a public repository. Review interior/home photos before publishing. More files are being added to this initial setup.
